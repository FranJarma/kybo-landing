# Barlow Condensed

Unmodified, locally served Latin WOFF2 files from the official Google Fonts distribution, downloaded 2026-11-21. The subset includes Spanish accents and punctuation.

- Bold (700): product names and customization heading.
- Black (900): carousel section heading.
- Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- License: SIL Open Font License 1.1, included in `OFL.txt`.

`next/font/local` registers these weights once as `--font-barlow-condensed`. The carousel body and filters reuse the existing `--font-barlow` family instead of loading a second copy of Barlow.
