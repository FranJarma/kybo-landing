# Barlow

Normal Barlow, Latin subset, weights 400, 500, 600, 700 and 800. The subset includes Spanish accents, ñ, inverted punctuation and the euro symbol.

Downloaded from the official Google Fonts CSS API on 2026-11-20 and served locally through `next/font/local`. The original font files are unmodified.

- Project: https://github.com/jpt/barlow
- Google Fonts distribution: https://github.com/google/fonts/tree/main/ofl/barlow
- License: SIL Open Font License 1.1, included in `OFL.txt`.

The supplied Kybo menu uses Barlow ExtraBold (800) for categories and Barlow Bold (700) for product names. The website follows those roles and adds Regular (400), Medium (500) and SemiBold (600) for longer copy and navigation.
